Writing
Entries counts entries; the other three count people. Entries, writers and new writers are signed-in accounts. Guests journal on their own phone, so the only guest event that ever reaches the server is their first entry — which is what new guest writers counts, once per guest, on the day they started.
How much guests write is not on this page. To estimate it, take the journal_entry_created count for the day in Firebase Analytics (it fires for guests too) and subtract Entries — a trend, not a figure: the two systems cut days in different timezones and offline saves reach the server late.
